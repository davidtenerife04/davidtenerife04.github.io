Repara imagen usando Windows Update.
powercfg /batteryreport
Genera salud de batería en HTML.
shutdown /r /fw /t 0
Reinicia directo en la BIOS/UEFI.
systeminfo
Resumen técnico completo del equipo.
tasklist /v
Lista procesos con usuario y memoria.
gpupdate /force
Fuerza actualización de políticas GPO.
driverquery /fo table
Tabla de todos los drivers instalados.
taskkill /F /FI "STATUS eq NOT RESPONDING"
Cierra programas bloqueados de golpe.
dxdiag
Herramienta de diagnóstico de DirectX.

Limpia la caché de resolución DNS.
netstat -ano
Puertos abiertos y PIDs vinculados.
netsh wlan show profile name="*" key=clear
Muestra claves WiFi guardadas.
pathping google.com
Traza ruta detectando pérdida de paquetes.
getmac /v
Dirección física detallada de red.
arp -a
Tabla de IPs y MACs en la red local.

Discos y Archivos

diskpart
ADMINGestor de particiones avanzado.
chkdsk C: /f /r
Repara sectores defectuosos en disco.
robocopy [origen] [dest] /mir
Espejo exacto entre dos carpetas.
cipher /w:C:
Borra permanentemente datos eliminados.
compact /c /s:C:\Ruta
Comprime archivos para ganar espacio.
tree /f
Gráfico de carpetas y archivos.
format D: /fs:ntfs /q
Formateo rápido de la unidad D:.
defrag C: /O
Optimiza y desfragmenta el disco C:.
vol C:
Ver etiqueta y serie de la unidad.
attrib +h +s +r [archivo]
Oculta archivo como súper protegido.

Gestión de Usuarios

net user
Lista todos los usuarios locales.
net user [nombre] [password] /add
ADMINCrea un nuevo usuario.
net localgroup Administradores [user] /add
Sube un usuario a Administrador.
net user [nombre] /delete
Elimina una cuenta de usuario.
whoami /priv
Muestra tus privilegios actuales.
net user [nombre] *
Cambia la contraseña de un usuario.
quser
Ver sesiones de usuario activas.
net accounts
Políticas de contraseñas y login.
control userpasswords2
Interfaz avanzada de gestión de usuarios.
msg [user] "mensaje"
Envía un mensaje a otro usuario en red.

Archivos y Búsqueda

ls -lahS
Lista por tamaño (grandes primero).

Busca configuraciones en todo el disco.
grep -ri "error" /var/log/
Busca "error" en todos los logs.

Comprime una carpeta en tar.gz.
du -sh * | sort -h
Espacio usado por carpeta ordenado.
chmod 755 [archivo]
Permisos de lectura/ejecución estándar.
chown user:group [archivo]
Cambia dueño y grupo del archivo.
cp -rv [orig] [dest]
Copia detallada de directorios.
ln -s [ruta] [enlace]
Crea un acceso directo (simlink).
locate [nombre]
Búsqueda instantánea en base de datos.
